## 🧩 About

**World of Warcraft Overlay Menu** is a curated list of World of Warcraft open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap markers, route notes
- **Quality-of-Life Helpers** — loot tracker, cooldown HUD, inventory notes
- **Research Notes** — quest routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Session Helpers
- Route Switcher — move between saved quest routes
- Marker Overlay — visualize map markers and points of interest
- Session Notes — record and review route runs
- HUD Scale — adjust overlay HUD for study (0.5x to 2x)

### 🎨 Catalog & Cosmetics
- Transmog Catalog — browse appearances and color sets
- Mount Notes — organize collected mounts
- Minimap Clarity — improved minimap visibility

### 🏋️ Layout Practice
- Route Notes — segment study on any zone layout
- Marker Control — manually toggle markers mid-run
- HUD Buffer Notes — chain complex route maneuvers
